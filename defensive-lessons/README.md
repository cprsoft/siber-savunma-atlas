# Defensive Lessons

Tekil bir olay veya yaygın yanlış kanıdan çıkarılan, genel uygulanabilir savunma prensipleri ("MFA tek başına yeterli değildir" gibi).

**Trust Tier:** 1 (hafif metodoloji)

**Kapsam içi:** Yaygın bir güvenlik yanılgısının düzeltilmesi, kavramsal açıklama, isimsiz/genel illüstrasyon, uygulanabilir kontrol önerisi.

**Kapsam dışı:** Belirli bir kurumun gerçek olay anlatımı, teknik istismar adımları.
