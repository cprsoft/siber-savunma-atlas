# Incident Briefs

Tekil, tarihsel siber olayların savunma odaklı analizi — "ne oldu, neden önemli, hangi savunma dersi çıkar".

**Trust Tier:** 3 (ağır metodoloji, attribution-sensitive — en az 5 onaylanmış PR geçmişi veya maintainer onayı gerekir)

**Kapsam içi:** Kamuya açık, çok kaynaklı olaylar; olay örgüsü ve etki düzeyinde anlatım (teknik istismar adımı değil).

**Kapsam dışı:** Devlet/aktöre kesin atıf (yalnızca "açık kaynaklarda ilişkilendirilmiştir" formu kabul edilir), teknik istismar zinciri, gerçek kurban verisi.
