# Defense Checklists

Bireyler, KOBİ'ler, geliştiriciler ve kurumlar için uygulanabilir, doğrudan kullanılabilir savunma kontrol listeleri.

**Trust Tier:** 1 (hafif metodoloji — Verified Facts/Analyst Assessment ayrımı zorunlu değil, kaynak zorunlu)

**Kapsam içi:** Düşük maliyetli, somut, sıra numaralı kontroller (MFA, yedekleme, yama yönetimi, parola politikası gibi).

**Kapsam dışı:** Belirli ürün/marka reklamı, kurumsal/büyük ölçekli mimari önerileri (bu, sector-risk-notes kapsamına girer).
